# Lumber for desktop

Downloads for Lumber's desktop app, the desktop half of [Lumber](https://lumber.infinitetoken.com): read your apps' end-to-end encrypted logs, decrypted on your own computer.

**[Download the latest version for Mac](https://github.com/infinitetoken/Lumber-Releases/releases/latest/download/Lumber.dmg)** (for Macs with Apple silicon), or see [the website](https://lumber.infinitetoken.com) for the iPhone app and help.

This repository only holds releases: the signed and notarized downloads, and the files Lumber checks to update itself. Help and support are at [lumber.infinitetoken.com](https://lumber.infinitetoken.com).

# Lumber for desktop

Downloads for Lumber's desktop app, the desktop half of [Lumber](https://lumber.infinitetoken.com): read your apps' end-to-end encrypted logs, decrypted on your own computer.

| | Download |
|---|---|
| **Mac** (Apple silicon) | [Lumber.dmg](https://github.com/infinitetoken/Lumber-Releases/releases/latest/download/Lumber.dmg) |
| **Ubuntu, Debian** and the distributions built on them | [lumber-desktop_amd64.deb](https://github.com/infinitetoken/Lumber-Releases/releases/latest/download/lumber-desktop_amd64.deb) (x86_64), [lumber-desktop_arm64.deb](https://github.com/infinitetoken/Lumber-Releases/releases/latest/download/lumber-desktop_arm64.deb) (arm64) |
| **Other Linux** | [Lumber-x86_64.AppImage](https://github.com/infinitetoken/Lumber-Releases/releases/latest/download/Lumber-x86_64.AppImage), [Lumber-arm64.AppImage](https://github.com/infinitetoken/Lumber-Releases/releases/latest/download/Lumber-arm64.AppImage) |

Each download updates itself from this repository's releases. On Windows, Lumber comes from the Microsoft Store, and on iPhone, iPad and Mac from the App Store; see [the website](https://lumber.infinitetoken.com) for those.

This repository only holds releases: the signed and notarized Mac download, the Linux packages, and the files Lumber checks to update itself. Help and support are at [lumber.infinitetoken.com](https://lumber.infinitetoken.com).
